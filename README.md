# TaskAcadémico 📚

Gestor de tareas académicas desarrollado con tecnologías web puras. Permite registrar, editar y eliminar tareas en tiempo real con persistencia en `localStorage`.

## Demo

Abre `index.html` directamente en tu navegador — no necesita servidor ni instalación.

## Funcionalidades

- ✅ Registrar tareas con nombre, materia, tipo, prioridad y fecha de entrega
- ✏️ Editar cualquier tarea mediante un modal
- 🗑️ Eliminar tareas con confirmación
- ☑️ Marcar tareas como completadas
- 🔍 Filtrar por: Todas / Pendientes / Completadas / Vencidas
- 📊 Estadísticas en tiempo real (total, pendientes, completadas)
- ⚠️ Indicador visual de tareas vencidas
- 💾 Persistencia automática con `localStorage`
- 🌙 Modo oscuro automático según preferencia del sistema
- 📱 Diseño responsive para móvil y escritorio
